# Cuerda Clave · Sitio web

## Cómo abrirlo
Abre la carpeta en VS Code, instala la extensión **Live Server**, clic derecho en `index.html` > *Open with Live Server*.
(Necesita internet solo para las fuentes de Google.)

## Estructura
```
cuerda-clave/
├── index.html          estructura: 3 variaciones (#v1, #v2, #v3)
├── css/styles.css      estilos y paleta (variables :root)
├── js/main.js          audio, ecualizador, filtros, menú y formulario
└── assets/
    ├── audio/claro-que-te-amo.mp3
    └── img/ (fotos y logos)
```
